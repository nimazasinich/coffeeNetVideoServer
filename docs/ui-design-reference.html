  • تصاویر: سبک LowPoly مثلثی

هویت سیستم

🔷 سبک بصری

سبک Neo-Tactile با پس‌زمینه تاریک عمیق. Glassmorphism + سایه‌های الکتریکی آبی. ظاهر نرم و مایع با depth واقعی.

🌑 تم

Dark Theme · پس‌زمینه Navy/Charcoal · اکسنت آبی الکتریکی (#1a6fdb → #38bdf8). گلاس افکت برای کارت‌ها.

⚙️ اصل اصلی

Glassmorphism کنترل‌شده. Focus Ring همیشه visible. Disabled: کنتراست کاهش + سایه حذف. Radius pill شکل برای دکمه‌ها.

🔵 Radius Steps

--neo-radius-sm: 10px; /* input, small card */ --neo-radius-md: 14px; /* card, modal */ --neo-radius-lg: 20px; /* panel, overlay */ --neo-radius-pill: 100px; /* button primary */

✨ Glassmorphism

backdrop-filter: blur(20px); background: rgba(255,255,255, 0.06); border: 1px solid rgba(255,255,255, 0.10); box-shadow: 0 8px 32px rgba(0,0,0, 0.3), inset 0 1px 0 rgba(255,255,255, 0.10);

💡 Focus Ring — همیشه نمایان

  • Focus ring همیشه visible است، حتی با ماوس
  • رنگ: rgba(56,189,248, 0.6)
  • offset: 3px — ضخامت: 2px
  • انیمیشن pulse برای جذب توجه

🚫 Disabled State

  • کنتراست کاهش می‌یابد: opacity 0.4
  • سایه کاملاً حذف می‌شود
  • cursor: not-allowed
  • هیچ blur یا glow نمی‌ماند
